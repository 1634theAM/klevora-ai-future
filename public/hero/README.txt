Drop the reference bridge photograph here as one of these filenames:

  bridge.jpg   (preferred)
  bridge.png
  bridge.webp

The component prefers .webp > .jpg > .png. It will auto-fall-back to a
procedural canvas bridge if none of the files exist, so the page never
breaks.

Recommended source image:
  - a photograph of stepping stones on misty water
  - warm sepia / cream tint (or we tint it in CSS)
  - landscape orientation, roughly 2400 x 1200 (or larger)
  - stones should curve from foreground-left to distant-upper-right
